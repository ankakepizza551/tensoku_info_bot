# 📊 東方非想天則 戦績管理BOT (Tensoku Match Stats Bot)

東方非想天則の対戦結果（戦績）をDiscord上で手軽に記録・集計するための Discord Bot です。
勝率や使用キャラクターごとの統計、サーバー内のリーダーボード（ランキング）に加え、
画像埋め込みや文字装飾を活用した記事風投稿機能も備えています。

---

## 🌟 主な機能とコマンド（スラッシュコマンド）

すべての主要機能は Discord の **スラッシュコマンド（`/`）** に対応しており、入力補完（オートコンプリート）を使って素早く入力できます。

---

### ⚔️ 戦績管理

#### 1. 戦績の登録 (`/report`)
対戦結果をデータベースに登録します。登録と同時に双方のレーティング（Eloレート）が自動計算・更新されます。
- **コマンド**: `/report opponent: [ユーザー] my_score: [勝利本数] opponent_score: [相手勝利本数] [my_char]: [自分のキャラ] [opponent_char]: [相手のキャラ]`
- **オプション**: 使用キャラクターは、入力時に非想天則の全20キャラからオートコンプリート選択が可能です。
- **結果**: 登録完了カード（Embed）が送信され、対戦結果と各プレイヤーのレーティング変動（例: `1500.0 -> 1516.0 (+16.0)`）が表示されます。

#### 2. 登録した戦績の削除 (`/delete_match`)
間違えて登録してしまった戦績をID指定で削除します。
- **コマンド**: `/delete_match match_id: [対戦ID]`
- **権限**: 報告者本人、またはサーバー管理者のみ削除可能です。
- **レーティング**: 削除完了時に、その対戦によって発生したレーティング変動も自動的に元の数値に巻き戻されます。

#### 3. 対戦相手の募集・マッチング自動化 (`/recruit`)
サーバー内で対戦相手を募集し、マッチング成立から結果報告までを自動化します。
- **コマンド**: `/recruit [comment: 募集コメント(任意)] [format: 募集形式(任意)]`
- **流れ**:
  1. 募集コマンドを実行すると、「対戦を申し込む」ボタンがついた募集Embedが送信されます。
  2. 別のプレイヤーがボタンを押すと「対戦中」状態へ遷移し、ボタンが「結果を報告する」に切り替わります。
  3. 対戦終了後、どちらかのプレイヤーがボタンを押すとスコアとキャラクター名を入力するモーダルが表示され、送信するだけで自動で戦績登録とElo計算が行われます。

#### 4. 個人戦績スタッツ表示 (`/stats`)
自分または他のプレイヤーの戦績データをグラフィカルな Embed で表示します。
- **コマンド**: `/stats [user: ユーザー(任意)]`
- **表示項目**:
  - レーティング（現在の強さを表すEloレート）
  - 総合戦績（総対戦数、勝敗数、勝率、勝率に応じたビジュアルバー `🟢/🔴`）
  - 使用キャラ TOP3（対戦数、勝敗、勝率）
  - よく戦う相手 TOP3（対戦数、勝敗、勝率）
  - 直近の対戦履歴（最大5件）

#### 5. サーバーリーダーボード表示 (`/leaderboard`)
サーバー内のプレイヤーの戦績ランキングを表示します。
- **コマンド**: `/leaderboard [min_matches: 最低必要対戦数(任意)]`
- **ソート**: レーティング（Eloレート）の高い順にソートされ、同レートの場合は勝率の高い順になります。

### 🎮 メインキャラクター分布

#### メインキャラクターの登録・変更 (`/main_char`)
自分が普段使っているメインキャラクターを登録します（1人1キャラ、いつでも変更可）。
- **コマンド**: `/main_char`
- 実行するとドロップダウンメニューが表示され、非想天則の全20キャラから選択するだけで登録・変更が完了します。

#### メインキャラクター分布・一覧表示 (`/main_char_list`)
サーバー内で誰がどのキャラクターをメインにしているか、分布と使用者一覧を表示します。
- **コマンド**: `/main_char_list`
- **表示項目**: キャラクターごとの登録人数（`X人 / 全体Y人`）・割合（ゲージ付き）
- ドロップダウンメニューでキャラクターを選ぶと、そのキャラの使用者一覧を自分にだけ表示できます。

#### メインキャラ登録パネルの設置 (`/main_char_panel`) ※管理者専用
「メインキャラを登録・変更」「分布を見る」の2つのボタンが付いた常設パネルをチャンネルに設置します。
- **コマンド**: `/main_char_panel [channel: 設置先チャンネル(任意)]`
- **権限**: サーバー管理者（`manage_guild`）のみ実行可能
- パネルのボタンはBot再起動後も動作し続けます（`/main_char` `/main_char_list` と同じ内容を、コマンドを打たずボタンから呼び出せます）。

### ✍️ 投稿補助（画像埋め込み・文字装飾）

#### 6. 記事風シンプル投稿 (`/post`)
モーダルを開いてタイトル・本文・画像URLをまとめて入力し、綺麗な Embed 投稿を1発で送信します。
- **コマンド**: `/post [color: カラーテーマ(任意)]`
- **カラー選択肢**: ブルー / グリーン / レッド / パープル / イエロー / オレンジ / ピンク / シアン / ホワイト
- **入力欄**:
  | 欄 | 説明 |
  |---|---|
  | タイトル | 省略可。Embedのタイトルになります |
  | 本文 | Discord書式（`**太字**`、`## 見出し`、`> 引用`など）フル対応。末尾に画像URLを貼ると自動で埋め込まれます |
  | 画像URL | PNG / JPG / GIF / WebP などの直リンクを指定するとメイン画像として大きく表示されます |

#### 7. フォーラムチャンネルへの新規投稿 (`/forum_post`)
フォーラムチャンネルの「最初の投稿（スレッド作成）」をBotのモーダルから行います。  
Discord標準のフォーラム投稿UIでは書式が限られますが、このコマンドなら画像埋め込みやDiscord書式をフル活用した綺麗な初回投稿が作れます。
- **コマンド**: `/forum_post channel: [フォーラムチャンネル] [color: カラーテーマ(任意)]`
- `channel` パラメータにはフォーラムチャンネルのみ選択できます
- **入力欄**:
  | 欄 | 説明 |
  |---|---|
  | スレッドタイトル | フォーラムポストのタイトル（必須、100文字以内） |
  | 本文 | Discord書式フル対応。末尾に画像URLで自動埋め込みも可 |
  | 画像URL | メイン画像を別途指定したい場合 |
- 投稿完了後、作成されたスレッドへのリンクが自分にだけ表示されます
- **必要権限**: BotロールまたはフォーラムチャンネルのBot権限に **「公開スレッドを作成」** が必要

#### 8. インタラクティブ Embed ビルダー (`/embed_builder`)
ボタン操作でステップごとに Embed を組み立て、プレビューを確認しながら投稿できます。
- **コマンド**: `/embed_builder`
- **操作ボタン**:
  | ボタン | 機能 |
  |---|---|
  | 📝 タイトル・本文 | タイトル / 本文 / フッターを編集（前回入力値が自動復元） |
  | 🖼️ 画像 | メイン画像URL（大きく表示）とサムネイルURL（右上に小さく表示）を設定 |
  | 🎨 カラー | 10色のドロップダウンから選択 → プレビューに即反映 |
  | ➕ フィールド追加 | フィールド名・内容・横並び表示(yes/no)を追加（最大10個） |
  | 🗑️ フィールド削除 | 最後に追加したフィールドを1件削除 |
  | 📤 投稿する | 下書きプレビューを消去し、投稿者名フッターを付けて本番投稿 |
  | ❌ キャンセル | 下書きプレビューを削除してキャンセル |

#### 8. 文字装飾チートシート表示 (`/format_help`)
Discord で使えるテキスト装飾・見出し・引用・画像埋め込みの書き方一覧を、自分にだけ見えるメッセージで表示します。
- **コマンド**: `/format_help`
- **内容**: 太字 / 斜体 / 下線 / 打ち消し / スポイラー / 見出し(H1〜H3) / 引用 / リスト / コードブロック / 絵文字・メンション の書き方と画像埋め込みのコツ

### 📊 アンケート・投票

#### 9. ボタン式投票アンケート (`/poll`)
ボタンをクリックして投票できる、複数選択対応のアンケートを作成します。  
投票結果はリアルタイムでプログレスバー付きに更新されます。

- **コマンド**: `/poll question: [質問文] options: [選択肢] [channel: 投稿先(任意)]`
- **選択肢の入力**: カンマ区切りで2〜10個まで指定可能  
  例: `霊夢,魔理沙,チルノ,パチュリー`
- **複数選択可**: 参加者は複数の選択肢に同時投票できます。ボタンを再クリックで取り消し
- **結果表示**: 各選択肢の得票数・参加人数比率をプログレスバーで表示
- **永続性**: Bot 再起動後もボタンが動作し続けます

#### 10. 投票を締め切る (`/close_poll`)
作成済みの投票アンケートを締め切り、最終結果を確定します。

- **コマンド**: `/close_poll message_id: [メッセージID]`
- **権限**: 作成者またはサーバー管理者のみ実行可能
- 締め切り後はボタンが無効化され、ステータスが「🔴 終了」に変わります

#### 11. テキスト回答式アンケート (`/survey`)
記述式（テキスト入力）アンケートをモーダルで作成します。参加者はボタンを押してフォームに記入します。

- **コマンド**: `/survey [channel: 投稿先(任意)]`
- **設定**: コマンド実行後にモーダルが開き、タイトルと最大4問の質問を設定
- **回答制限**: 1人1回のみ回答可能（重複防止）
- **回答データ**: すべての回答がデータベースに保存され、後から確認可能

#### 12. アンケートを締め切る (`/close_survey`)
テキスト回答式アンケートを締め切ります。

- **コマンド**: `/close_survey message_id: [メッセージID]`
- **権限**: 作成者またはサーバー管理者のみ実行可能

#### 13. アンケート結果を確認する (`/survey_results`)
テキスト回答式アンケートの個別回答をすべて確認します（自分にだけ表示）。

- **コマンド**: `/survey_results message_id: [メッセージID]`
- **権限**: 作成者またはサーバー管理者のみ実行可能
- 件数サマリー + 個別回答（最大9件）を Embed で表示します

> **メッセージID の確認方法**: `/poll` または `/survey` 実行後、Botから返信されるメッセージにIDが記載されます。Discordの「開発者モード」をオンにしてメッセージを右クリック →「IDをコピー」でも取得できます。

### 📨 匿名お便り

#### 14. 匿名お便りを送る (`/tegami`)
匿名でサーバー管理者宛にメッセージを送信できます。送信者名は通常チャンネルには表示されません。
- **コマンド**: `/tegami`
- **入力欄**: タイトル（件名）と本文
- 送信先チャンネルは環境変数 `LETTER_ADMIN_CHANNEL_ID` で設定します。

#### 15. お便りの送信者確認 (`/tegami_check`) ※管理者専用
お便りの送信者を番号（No.）で確認します。確認ログも管理チャンネルに自動記録されます。
- **コマンド**: `/tegami_check letter_id: [お便りNo.]`
- **権限**: サーバー管理者（Administrator）のみ実行可能

### 🎥 陣取りマップ 配信オーバーレイ (OBS)

陣取りゲームの陣地マップを配信画面に映すための、OBS ブラウザソース用ページです。Bot 本体に組み込まれた軽量 Web サーバー（`overlay/server.py`）が提供します。

- **URL**: `https://<RailwayでこのBotに割り当てた公開ドメイン>/territory?guild_id=<サーバーのID>`
- 背景は透過なので、そのまま配信画面に重ねられます。3秒ごとに自動更新され、マス目が変化した陣地は色がフェードで切り替わります。
- **サーバーIDの調べ方**: Discordの「開発者モード」をオンにし、サーバーアイコンを右クリック →「サーバーIDをコピー」。
- **公開設定（初回のみ）**: RailwayのダッシュボードでこのBotのサービスを開き、「Settings」→「Networking」から Public Domain を発行してください（Procfile上は `worker` ですが、ポートを開けば通常どおり公開URLが使えます）。
- **アクセス制限（任意）**: `.env` に `TERRITORY_OVERLAY_TOKEN=好きな文字列` を設定すると、URLに `&token=同じ文字列` を付けないとマップが表示されなくなります。第三者にURLが漏れても見られたくない場合に設定してください。

### 📣 サーバー宣伝

#### X(Twitter)で宣伝 (`/promote`)
サーバーをX（旧Twitter）で宣伝できるボタンを表示します。
- **コマンド**: `/promote`
- ボタンを押すと、固定の宣伝文＋サーバー招待リンクが入力された状態でXの投稿画面（Web Intent）が開き、内容を確認してそのままポストできます。Botのアカウントで投稿されることはありません。
- 事前に `.env` の `SERVER_INVITE_URL` にサーバーの招待リンクを設定しておく必要があります（未設定の場合はエラーメッセージが表示されます）。

## 🛠️ 管理者（オーナー）専用コマンド

プレフィックスコマンド（デフォルト `!`）で実行する、Botのオーナー専用コマンドです。

- **`!sync`**: スラッシュコマンドをグローバルに同期します（反映まで最大1時間）。
- **`!sync guild`**: 現在のサーバーのみに即時同期します（テスト・更新時に便利）。
- **`!bot_status`**: 接続サーバー数、レイテンシ、稼働中のモジュールの一覧を表示します。

## 🚀 導入・セットアップ方法

### 1. 前提要件
- Python 3.8 以上
- SQLite3 (Python標準搭載)
- Discord Bot アカウント（以下の Intent を有効にしてください）
  - **Message Content Intent**
  - **Server Members Intent**

### 2. インストール
```bash
pip install -r requirements.txt
```

### 3. 環境設定
`.env` ファイルをプロジェクトルートに作成し、以下を記述します。
```env
DISCORD_TOKEN=ここにDiscord_Botのトークンを記入
BOT_PREFIX=!
DB_PATH=data/tensoku_stats.db
LETTER_ADMIN_CHANNEL_ID=匿名お便りの送信先チャンネルID（数字）
SERVER_INVITE_URL=https://discord.gg/xxxxxxxx （/promote で使うサーバー招待リンク）
```

### 4. 起動
```bash
python main.py
```
起動すると `data/tensoku_stats.db` が自動作成・初期化されます。  
起動後、Discord 上で Bot のオーナーアカウントから `!sync guild` を送信してスラッシュコマンドを同期してください。

## 📂 フォルダ構成

```text
tensoku_info_bot/
├── cogs/
│   ├── letter_cog.py   # 匿名お便り (/tegami, /tegami_check)
│   ├── poll_cog.py     # アンケート・投票 (/poll, /close_poll, /survey, /close_survey, /survey_results)
│   ├── post_cog.py     # 投稿補助・文字装飾 (/post, /forum_post, /embed_builder, /format_help)
│   ├── promote_cog.py  # サーバー宣伝 (/promote)
│   ├── recruit_cog.py  # 対戦募集・マッチング自動化 (/recruit)
│   ├── report_cog.py   # 戦績の登録と削除 (/report, /delete_match)
│   └── stats_cog.py    # スタッツとランキング表示 (/stats, /leaderboard)
├── database/
│   └── db_manager.py   # SQLiteデータベース操作・集計・レーティング計算ロジック
├── config.py           # 環境設定の読み込み
├── main.py             # Botのエントリーポイント
├── requirements.txt    # 依存ライブラリ
├── .env                # 設定値ファイル (作成が必要、gitignore済み)
└── README.md           # このファイル
```
